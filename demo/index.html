Set the mode

Beacon stations keep taking contact punches as well. SIAC special stations do not — they perform that one function only, and their control code is set for them.

Punch handling

The station does one or the other: the hardware ties handshake and auto-send together as opposites.

Settings

Changes are written to the station as you make them.

Control code

1 to 1023. Codes above 255 keep their top bits in the feedback byte, so the station writes both at once.

Punch feedback

Applied as you tick them. Use the beep button to hear the difference.

Awake time

Minutes awake after a punch, max 5759. In AIR+ mode a contactless punch does not restart it — only a direct punch does — so allow for the whole event. SPORTident suggest 720.

Protocol

Extended protocol is needed for backup memory and for relaying to a remote station.

Remote station

The cabled station can relay to a second one standing on its coupling stick, so it can be configured without being plugged in.

Where commands go

A sleeping station takes a while to rouse — 11 and 23 seconds on the two measured here — so allow up to half a minute. Every command goes to the selected station, including the destructive ones.
